**Context** is everything the model sees for a task — no information exists outside it. And: **a language model is stateless.** What looks like memory is not — the entire history is resent with every call.

## What a request consists of

| Part | In Claude Code concretely | Changes |
| --- | --- | --- |
| Tool definitions | built-in tools + active MCP servers | rarely |
| System prompt | includes the project's CLAUDE.md | rarely |
| History | your tasks + every tool result (files read, test output) | grows steadily |
| Current message | the new task | every time |

The order is technically relevant: it determines what can be cached → [Prompt Caching](../prompt-caching/).

<Callout type="merke">
The system prompt is not a privileged zone with special authority — just text at a particular position. It works because it comes first and models are trained to take it seriously. That is exactly what [Prompt Injection](../prompt-injection/) hinges on.
</Callout>

## What follows from statelessness

- **Cost grows disproportionately.** Every turn resends all previous ones — turn 30 pays for turn 1 for the thirtieth time.
- **Nothing goes away on its own.** A misunderstanding from turn 3 still shapes turn 15.
- **Tool results are the biggest item.** Three Java classes read stay in context until the session ends — long after the work on them is done. A single tool call can consume more than twenty conversational turns.

<Callout type="praxis">
Session stuck, same mistake repeating? Don't press harder — `/clear` and restate the task cleanly. The old history pulls the answer back towards what was already wrong once.
</Callout>

## Context engineering

The guiding question of every session:

> What information does the model need for this task — and how do I get exactly that in without dragging everything else along?

The tools for it run through this tutorial: [skills](../skills/) load instructions only on demand, [sub-agents](../multi-agent/) keep research out of the main thread, compaction summarises old turns.

<KeyTakeaway>
- Context is everything the model sees — models are stateless, the history travels along in full every time.
- That is why cost grows disproportionately and old mistakes stay in effect.
- Tool results (files read, test output) fill the context faster than the conversation itself.
- For stuck sessions: `/clear` instead of pressing harder.
</KeyTakeaway>
